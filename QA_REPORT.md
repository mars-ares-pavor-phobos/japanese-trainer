# Проверка приложения

## Запуск

```sh
npm test
npm run test:ui
```

`npm test` проверяет данные и логику без запуска браузера. `npm run test:ui` запускает сценарии Playwright. Параметры установки движков приведены в README.

## Сценарии

| Файл | Область проверки |
| --- | --- |
| `bank.test.cjs` | Структура заданий, варианты ответа, спряжение, фуригана |
| `verbs.test.cjs` | Группы глаголов, чтения, преобразования, четыре формы |
| `core.test.cjs` | Отбор вопросов, циклы, перестановки, повторные события |
| `session.test.cjs` | Сериализация, восстановление, проверка сохранений |
| `interface.test.cjs` | Локализация, разметка, отсутствие inline-обработчиков |
| `browser.cjs` | Навигация, клавиатура, варианты ответа, результаты |
| `browser-session.cjs` | Восстановление, выход, сброс, ошибки хранилища |
| `browser-reopen.cjs` | Повторное открытие браузера с сохранённой тренировкой |
| `browser-lessons.cjs` | Практика по глаголам и возврат к уроку |
| `browser-typography.cjs` | Целостность слов, таблицы, масштабирование текста |
| `browser-furigana.cjs` | Чтения во всех учебных блоках, смена языка |
| `browser-titlecase.cjs` | Регистр подписей на обоих языках, отсутствие выбора исходной формы |

## Условия корректности

- Ответ принимается один раз для текущего вопроса. Повторный или устаревший вызов не меняет результат.
- Смена языка сохраняет вопрос, порядок вариантов и ответ.
- После перезагрузки восстанавливаются вопросы, варианты, ответы и позиция в цикле.
- Завершение фиксируется после последней команды завершения. Выход сохраняет неполный результат.
- При восстановлении проверяются ID, порядок вариантов, непрерывность ответов, тема и версия данных. Правильность ответа определяется по текущему набору заданий.
- Ошибка `localStorage` не прерывает тренировку; приложение сообщает, что прогресс может быть потерян.
- Кандзи в учебном тексте имеют фуригану. Окуригана остаётся вне `ruby`; чтение зависит от формы слова.
- На ширинах 320–1440 px и при размере текста 100% / 200% страница не расширяется. Длинные японские формы прокручиваются внутри своего блока.

Браузерные сценарии сохраняют снимки в `test-results/`. Эмуляция не заменяет проверку на физических устройствах и с программами экранного доступа. Одновременная работа нескольких вкладок не синхронизируется; сохраняется последнее записанное состояние.
