# Тренажер Простой Формы

Статическое приложение для изучения японской простой формы (普通形) на русском и узбекском языках. Работает без сборки и сетевых запросов.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```sh
python3 -m http.server 8000
```

Для размещения на статическом хостинге нужны `index.html`, `style.css` и шесть JavaScript-файлов из корня проекта.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разделы приложения и элементы управления |
| `style.css` | Типографика, компоненты, адаптивная вёрстка |
| `script.js` | Локализация, отображение, делегирование событий |
| `verbs.js` | 50 глаголов, их формы и правила преобразования |
| `lessons.js` | Карточки глаголов и таблица окончаний |
| `questions.js` | 240 заданий на глаголы, прилагательные и существительные |
| `core.js` | Отбор вопросов, перемешивание и подсчёт ответов |
| `session.js` | Проверка и сохранение состояния в `localStorage` |
| `tests/` | Проверки данных, логики и интерфейса |

## Учебные данные

Каждое задание содержит четыре варианта и один правильный ответ. Поля `id` уникальны; правильность определяется `isCorrect`, а не порядком вариантов. `lexeme` хранит исходное слово. Поля `tense` и `polarity` также входят в `tags`.

Группа глагола задаётся явно. Словарная форма обозначает только утвердительную форму настоящего/будущего времени. Чтение кандзи размечается через `ruby` и `rt`; окуригана остаётся за пределами `ruby`. У существительных и な-прилагательных варианты ответа содержат слово со связкой целиком.

Глагольные задания начинаются от формы на ます. Общая тренировка включает до 20 разных слов. Отбор балансирует формы и темы; вопросы повторяются после исчерпания цикла выбранной темы. Если оставшийся набор не позволяет соблюсти все условия, тренировка содержит меньше заданий. Отдельное упражнение на глагол проверяет четыре его формы.

## Сохранение

Приложение сохраняет одну последнюю тренировку: вопросы, порядок вариантов, ответы, язык и циклы тем. Смена раздела или языка не завершает тренировку.

- **Продолжить** восстанавливает текущий вопрос.
- **Начать заново** удаляет ответы и открывает выбор темы. Выданные вопросы остаются использованными в цикле.
- **Выйти из тренировки** сохраняет неполный результат и открывает выбор темы.

Сохранение привязано к браузеру и адресу страницы. Данные между устройствами не переносятся. При недоступном хранилище приложение сообщает об ошибке; работа в открытой вкладке продолжается.

## Подписи интерфейса

Заголовки и управляющие подписи оформляются в Title Case на обоих языках. Предлоги, союзы, частицы и узбекские послелоги пишутся со строчной буквы, кроме первого слова. Статические подписи заданы в `i18n` и `posNames`; динамические обрабатывает `titleCaseLabel`. Учебные пояснения сохраняют обычный регистр предложений.

## Проверки

Требуется Node.js 20 или новее. Проверки данных и логики:

```sh
npm test
```

Браузерные проверки:

```sh
npm ci
npx playwright install chromium
npm run test:ui
```

Для WebKit установите его через `npx playwright install webkit` и выполните `BROWSER=webkit npm run test:ui`. Путь к установленному движку можно передать через `CHROMIUM_PATH` или `WEBKIT_PATH`.

Проверяются оба языка, задания, восстановление прогресса, клавиатура, повторные события, фуригана и вёрстка на ширинах 320–1440 px при размере текста 100% и 200%. Снимки сохраняются в `test-results/`.
