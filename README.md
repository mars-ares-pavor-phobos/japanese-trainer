# Тренажер Простой Формы

Статическое приложение на русском и узбекском для изучения четырёх простых форм глаголов, い-прилагательных, な-прилагательных и существительных. Сборка и сетевые запросы приложению не нужны.

## Ручная Публикация

1. Распакуйте ZIP.
2. Замените файлы приложения в той же папке репозитория, которая сейчас публикуется через GitHub Pages. В архиве `index.html` находится на верхнем уровне.
3. Для самого сайта необходимы `index.html`, `style.css`, `verbs.js`, `lessons.js`, `questions.js`, `core.js`, `session.js`, `script.js`. Загрузите их вместе, чтобы код и данные были одной версии.
4. Дождитесь публикации и обновите страницу. Старые сохранения текущей исходной версии поддерживаются. Для сохранения прогресса оставьте прежний адрес сайта и не очищайте данные браузера.

Из этой рабочей среды сайт и репозиторий не публиковались и не изменялись удалённо. Готовые изменения находятся в этом архиве.

## Локальный Запуск

Можно открыть `index.html` непосредственно или запустить сервер из папки приложения:

```sh
python3 -m http.server 8000
```

Для проверки сохранения рекомендуется сервер: браузеры по-разному ограничивают `localStorage` у локальных файлов.

## Что Изменено

- Основная схема каждого слова: время, утверждение, отрицание. Все четыре полные формы открыты; отдельная таблица показывает конкретные изменения.
- Глаголы объясняются от ます, неглагольные формы от です. Девять моделей I группы, исключения и различия групп показаны рядом с правилами.
- Короткие упражнения по прилагательным и существительным теперь охватывают четыре формы; прежние незавершённые наборы можно закончить.
- После ответа отображается объяснение. Кнопка перехода доступна через полные 5 секунд; автоматического перехода нет.
- Сохраняются язык, вопросы, порядок вариантов, ответы и остаток задержки. Старый режим заданий от словарной формы восстанавливается с объяснением от ます.
- Теория формируется только при открытии темы или смене языка. Убраны старые интерактивные плитки и повторные вычисления в подборе вопросов.
- Исходные цвета, шрифтовые семейства и радиусы сохранены. На узком экране широкая таблица прокручивается внутри своей области, сохраняя заголовки. Область доступна с клавиатуры.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html`, `style.css` | Разметка и оформление |
| `script.js` | Интерфейс, языки, события, таймер |
| `lessons.js` | Открытая теория и учебные таблицы |
| `verbs.js` | 50 глаголов, четыре формы и пошаговые преобразования |
| `questions.js` | 240 основных заданий |
| `core.js`, `session.js` | Подбор вопросов, ответы и сохранение |
| `tests/` | Автоматические проверки |
| `LANGUAGE_REVIEW.md` | Языковые исправления и учебные источники |
| `QA_REPORT.md` | Фактически выполненные проверки и ограничения |

Помимо основного банка, из глагольных записей формируются 200 вопросов для упражнений на четыре формы. Новые зависимости приложения не добавлены.

## Проверки

Проверки данных и модели требуют Node.js 20 или новее и не требуют установки пакетов:

```sh
npm test
```

Браузерный сценарий подготовлен, но в этой среде не выполнен. Для самостоятельного запуска:

```sh
npm ci
npx playwright install chromium
npm run test:ui
```

Можно использовать WebKit: установите `npx playwright install webkit`, затем выполните `BROWSER=webkit npm run test:ui`. Существующий исполняемый файл браузера задаётся через `CHROMIUM_PATH` или `WEBKIT_PATH`.

Сценарий проверяет 6 тем, оба языка, восемь размеров окна в обеих ориентациях, текст 100%/200%, таймер, восстановление, клавиатурный переход и результаты. Снимки для ручного просмотра сохраняются в `test-results/`. Наличие этого сценария не означает, что визуальная проверка выполнена.
